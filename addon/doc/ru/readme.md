# Доступность Telegram Desktop для NVDA

## Обзор

«Доступность Telegram Desktop» — дополнение NVDA для Telegram Desktop в Windows. Оно добавляет команды быстрого перехода и управления звонком, не изменяя встроенные функции доступности и названия элементов Telegram.

## Возможности

* `Alt+1` перемещает фокус на выбранный чат в списке чатов, а если чат не выбран — на первый чат.
* `Alt+M` открывает главное меню Telegram.
* `Alt+Y`, `Alt+N`, `Alt+A` и `Alt+V` отвечают на звонок, отклоняют или завершают его, включают и выключают микрофон, а также включают и выключают камеру. Каждая команда сообщает о выполненном действии словами самого Telegram, поэтому следует языку интерфейса Telegram.
* Все команды отображаются в диалоге NVDA «Жесты ввода» в категории «Telegram Desktop Accessibility», поэтому любое сочетание по умолчанию можно переназначить или удалить. За пределами Telegram назначенное сочетание без изменений передаётся приложению.
* Структурные элементы главного меню, например «Профиль» и «Аккаунты», безымянные элементы панели ввода и подсказка в верхней панели получают понятные доступные названия. Настоящее название, предоставленное Telegram, всегда сохраняется.
* Если UnigramPlus или другое установленное дополнение занимает общий слот модуля приложения Telegram, запасной механизм с проверкой активного окна сохраняет эти сочетания и названия. За пределами Telegram сочетания не перехватываются.
* Элементы списка чатов и звонка определяются по стабильным сведениям о классе UIA, а не по переведённому названию элемента, поэтому команды не зависят от языка интерфейса Telegram.
* Элементы, которые предоставляют только внутренний путь класса C++ из Telegram, больше не проговаривают этот путь. Остальные названия из Telegram не заменяются.

## Использование

Установите дополнение, перезапустите NVDA по запросу и используйте команды дополнения в главном окне Telegram. Дополнительная настройка не требуется.

Если `Alt+1` не может найти список чатов или список пуст, NVDA сообщит причину. Если на текущем экране Telegram главное меню недоступно, при нажатии `Alt+M` NVDA сообщит об этом. Когда нужный элемент отсутствует на экране, команды звонка сообщают, что входящего звонка нет или что вы не находитесь в звонке. Звонок идёт в отдельном окне, поэтому команды звонка работают и тогда, когда впереди главное окно Telegram.

Чтобы использовать другие клавиши, откройте «Меню NVDA» > «Параметры» > «Жесты ввода», разверните категорию «Telegram Desktop Accessibility» и добавьте или удалите жест для нужной команды.

## Реализация

Исправленный поставщик специальных возможностей Qt в Telegram Desktop предоставляет через UIA имена классов RTTI. Дополнение определяет список чатов по классу `Dialogs::InnerWidget`, не сравнивая локализованное доступное имя. Команда главного меню находит встроенную кнопку Telegram проверкой точки UIA рядом с левым верхним углом, поддерживая как макет `Dialogs::Widget`, так и боковую панель папок, а затем при необходимости возвращается к прежнему запросу поддерева на стороне поставщика.

Панель звонка Telegram создаёт каждый элемент как `Ui::CallButton` и располагает их в ряд: демонстрация экрана, камера, отмена или отклонение, ответ или завершение, микрофон, добавление участников. Только у камеры и микрофона есть угловая кнопка выбора устройства, поэтому дополнение узнаёт их именно по ней, а остальные — по месту в этом ряду. Для поиска элемента переведённое название не читается: имя считывается только для сообщения о действии, потому что каждая кнопка названа по тому, что она делает при нажатии.

Все команды принадлежат глобальному плагину, который определяет модуль приложения этого дополнения по его владельцу и обходит общий поиск `appModules/telegram.py`, если его занимает другое дополнение. Именно единственное определение команд в постоянно работающем плагине оставляет в диалоге NVDA «Жесты ввода» по одной переназначаемой записи на команду; каждая команда сама проверяет активное окно и передаёт свой жест приложению, когда Telegram не впереди.
